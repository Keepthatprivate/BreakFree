PROJECT NAME: Break Free Quiz 2.0 — Ripple Evolution Upgrade

OBJECTIVE:
Transform the existing Break Free Quiz web app into an immersive, water-themed healing experience
while preserving all existing backend logic (quiz scoring, Stripe payments, email automations).
The result must visually and emotionally align with the “Emotional Lake” concept, with subtle
chapter evolution, ripple animations, and a blurred-result reveal before payment.

====================================================================
GLOBAL DESIGN SPECIFICATIONS
====================================================================

1. GENERAL THEME
   • Background color: #0d0d16 (bluish-black)
   • Accent color: #54d3bb (teal)
   • Text color: #ffffff
   • Font families:
       - Inter (UI, buttons, questions)
       - Lora (Empathy messages, titles)
   • Border radius: 16px
   • Shadow: soft, rgba(0,0,0,0.35), blur 12px
   • Motion timing: 300–400ms ease-out (respect prefers-reduced-motion)
   • Mobile-first responsive layout (single-column, centered card)
   • Max load time mobile 4G: <2.0s

2. UI COMPONENT STYLE TOKENS
   • Buttons: solid teal background, white text, radius 12px, hover glow
   • Cards: semi-transparent #111a22 with backdrop-filter: blur(8px)
   • Progress indicators: thin teal bar at top (4px height)
   • CTA sections: use gradient accent (teal → deep navy)

====================================================================
LANDING PAGE (index.html)
====================================================================

Structure:
  - Fullscreen centered hero section.
  - Background: looped Lottie “chapter-bg-1.json” (dark still water).
  - Overlay headline:
      H1: “Break Free Quiz”
      Sub: “Each choice creates a ripple. See what your reflection reveals.”
  - CTA button [Begin the Quiz] → routes to /quiz.html

====================================================================
QUIZ PAGE (quiz.html + quiz.js)
====================================================================

1. Layout:
   - Fixed background (Lottie container) filling viewport.
   - Center card for question content.
   - Top progress bar showing chapter progression.
   - Question area uses radio, slider, emoji-grid, or image format.
   - “Next” button anchored bottom center.

2. Chapters & Background Evolution:
   - Chapter 1 → load “chapter-bg-1.json” (still water).
   - Chapter 2 → crossfade to “chapter-bg-2.json”.
   - Chapter 3 → crossfade to “chapter-bg-3.json”.
   - Chapter 4 → crossfade to “chapter-bg-4.json”.
   - Background changes triggered by chapter index (1–4).
   - Crossfade duration: 400ms, opacity interpolation.

3. Ripple Interaction:
   - On each answer select or slider change, play “ripple-pulse.json”
     behind the card (center screen). Duration: 1s.
   - Use CSS transform scale(1.2) fade-out for light bloom effect.

4. Empathy Breaks:
   - After final question of each chapter, show empathy message overlay:
       - Fade out quiz card → fade in message from empathyMessages.js
       - Stay 2.5s → fade out → next chapter loads.
   - Each empathy message: 1–2 poetic sentences (see empathyMessages.js).

5. State Saving:
   - Use localStorage to store current question index, chapter, and answers.
   - Auto-resume if user refreshes or exits mid-quiz.

====================================================================
RESULTS FLOW (results.html + results.js)
====================================================================

1. Stage A – “Scanning Reflection” (pre-payment)
   - Background: dim “chapter-bg-4.json”
   - Overlay text:
       “The surface is calming… your reflection is forming.”
   - Disabled button: “Reveal My Reflection →”

2. Stage B – “Blurred Tease”
   - Show blurred static image or blurred div with CSS:
       filter: blur(12px)
   - Overlay:
       “Your reflection holds your core emotional patterns.”
       CTA button:
         [Unlock My Reflection – 7-Day Trial €1]
   - Button triggers Stripe checkout (payments.js).

3. Stage C – Payment Success Reveal
   - Stripe webhook (payments.js) listens for success event → localStorage flag.
   - On redirect, remove blur with transition:
       duration 1s → blur:12px → blur:0px
   - Show personalized result visualization (same scoring engine as v1).
   - Headline: “This is your emotional reflection.”
   - Subtext: “You’ve brought calm to the surface—now let’s deepen it.”
   - CTA: [Start 7-Day Healing Plan]

4. Result Visualization:
   - Use existing trauma-type scoring logic (Abandonment, Control, Neglect, Trust).
   - Overlay small SVG ripple pattern variant:
       - Abandonment → fast expanding circles
       - Control → tight concentric rings
       - Neglect → faint, dissolving waves
       - Trust → intersecting ripples
   - Each paired with one-sentence insight and micro-practice suggestion.

====================================================================
PAYMENT INTEGRATION (payments.js)
====================================================================

1. Keep existing Stripe public + secret keys.
2. Use unified Stripe Checkout for:
   - Donation
   - €1 Trial
   - €14.99 Guides Upsell
3. After successful payment:
   - Stripe webhook posts to /webhook endpoint (existing logic)
   - On frontend, set localStorage key `paid=true`
   - Redirect to /results.html with URL param ?paid=1
4. If user tries to access results without payment:
   - Show blurred tease variant.
